IP Names in Urls

When you look at a web address, you usually see a name like "google.com." This is a domain name, and it's how most legitimate websites are accessed. A major red flag in a phishing email is a link that uses a string of numbers, known as an IP address, instead of a name.

An IP address looks something like http://192.168.1.1/login.html. Legitimate companies almost never use raw IP addresses in links for their public services like email or banking. They use domain names because they are easier for people to remember and trust. Using an IP address is a common trick for attackers because it helps them hide.

By using a direct IP address, the attacker does not have to buy a suspicious-looking domain name like "secure-paypa1.com." They can simply host their fake login page on a server and link directly to its numeric address. This makes the link look more technical and can sometimes bypass simple security filters that are only looking for bad domain names. If you see a link in an email that is just a set of numbers, it is a very strong sign that you are looking at a phishing attempt.
