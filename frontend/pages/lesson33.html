Lesson 33

Detection via Link Analysis

URL and link analysis target the conversion vector of phishing: the landing site. The analysis pipeline performs layered expansion and normalization—resolving URL shorteners, following redirect chains, normalizing punycode and percent-encoding, and recording each intermediate domain and HTTP response. Lexical analysis measures domain similarity to legitimate assets (edit distance, token overlap), analyzes token distributions in paths and queries, and assesses entropy and randomness consistent with automated domain generation. DNS and WHOIS telemetry contribute temporal signals: recent registration dates, privacy-protected WHOIS, and rapid registry changes are strong indicators in commodity phishing campaigns.

Reputational signals are combined with dynamic behavior checks. TLS certificate analysis inspects issuer, validity window, subject alternative names, and anomalies (self-signed, mismatched CN). Dynamic rendering—headless browser instrumentation—captures page structure, form presence, and script behaviors, revealing credential-capture forms, auto-submitting scripts, or drive-by download attempts. Operationally, systems adopt tiering: known-malicious hosts are blocked via blacklists and threat feeds; high-risk but unknown domains are placed into sandbox-inspection or proxied with user interstitial warnings; low-risk domains are monitored and cataloged.

The pragmatic challenge is scale and latency. Real-time mailflow cannot afford full dynamic rendering for every link; triage uses fast lexical and reputation heuristics to triage. Machine models trained on link features output continuous risk scores used to decide which URLs require deeper analysis. The architecture must also handle the adversary pattern of rapid domain churn; threat hunting layers use clustering across temporal windows (shared hosting, identical payloads, overlapping token signatures) to detect low-volume targeted campaigns that evade thresholded defenses. Finally, post-click telemetry—if available through secure browsing proxies—feeds back into models, closing the loop between detection and operational containment.
