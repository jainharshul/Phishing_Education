Punycode for Homograph Attacks/IDN Homograph attack

A sophisticated phishing trick involves creating fake website addresses that look identical to real ones. This is called a homograph attack, and it works by exploiting international domain names (IDN). Because the internet supports different languages, attackers can register domains using foreign characters that look exactly like English letters.

For example, the real domain is apple.com. An attacker could create a fake domain that looks the same to the human eye, but is actually spelled using Cyrillic characters: аррӏе.com. In your email, the link might show the perfectly convincing text "Click here to go to apple.com," but the underlying href code points to the fake, international domain.

To see the real address and spot this trick, you must look at the link in the email's raw source. In the raw code, international domains are converted into a special format called "Punycode," which begins with xn--. A legitimate link to apple.com will just show apple.com in the source. A homograph attack will show a confusing string like xn--80ak6aa92e.com instead of the expected domain name. If you see "xn--" in a link for a company that shouldn't need international characters, it is a major red flag. Always ask if the domain name makes sense, as these attacks rely on you trusting what you see at a quick glance.
