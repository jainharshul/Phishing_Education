Most Dangerous File Types

Phishing emails often try to trick you into opening a file that will infect your computer. While many file types are safe, attackers rely on a few specific categories that are designed to run code or hide malicious software. Knowing which file types are most dangerous is a key part of your defense.

The most obvious dangerous files are executables. These are programs designed to run directly on your computer. Common examples include .exe, .scr (which can be a screensaver but also an executable), .msi (a Windows installer), and script files like .bat and .cmd. An email from a stranger with one of these file types attached is almost always an attack.

A more sneaky category is macro-enabled documents. These are files for programs like Word, Excel, and PowerPoint, but with a dangerous difference. Files ending in .docm, .xlsm, and .pptm can contain embedded code, called "macros," that can be used to install malware. This is different from the safer .docx, .xlsx, and .pptx files, which cannot contain this type of code. Attackers send these files hoping you will enable the macros, which then infects your system.

Finally, attackers often hide these dangerous files inside archive files. Formats like .zip, .rar, and .7z are used to compress and bundle multiple files together. An attacker will put a malicious .exe or .docm file inside a .zip file to help it bypass email filters that might block the dangerous file on its own. You should always be very cautious about opening any archive file from an untrusted source.
